# 提示词目录

所有固定 LLM 提示词统一存放于此。业务代码通过 `load_prompt()` 读取固定正文，或通过
`render_prompt()` 渲染 `[[variable_name]]` 占位符。

- JSON 花括号可以原样书写，不需要转义。
- 一个文件包含多条消息时，以 `## Prompt N`、`## System`、`## User`、`## Intro`、
  `## Output` 分段；其他二级标题是提示词正文，不会截断分段。
- 用户输入、RAG 内容和流程控制消息保留在业务代码中。
- 变量名只允许英文字母、数字和下划线，并且必须由字母或下划线开头。
- 渲染会严格检查缺失变量、额外变量和路径越界；报错时先核对调用处字典键与模板占位符。
- 加载器按文件修改时间缓存，开发环境修改 `.md` 后无需重启即可读取新内容。

目录按调用场景分为：`agent_workspace/`、`recruitment/`、`interview/`、`talent/`、
`resume_scoring/` 和 `ai_services/`。新增提示词时放入对应业务域，不要再把固定长模板写回
Python 文件。
