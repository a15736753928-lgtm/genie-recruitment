# 知识库检索技能

## 工作流

1. **语义检索**：`rag_search` → 用自然语言查询知识库，返回最相关的文档片段
2. **分类浏览**：`list_knowledge` → 按分类查看知识库素材
3. **全文查看**：根据检索结果中的文档 ID，使用相关接口查看完整内容

## 知识库结构

| 分类 | 内容 | 典型查询 |
|------|------|---------|
| interview | 面试题库、评分标准 | "Java面试题""算法题" |
| policy | 公司制度、HR 政策 | "考勤制度""报销流程" |
| tech | 技术规范、架构文档 | "代码规范""API设计规范" |
| other | 其他参考资料 | 各类通用文档 |

## 检索策略

- 查询尽可能具体："Java 并发编程面试题" 而非 "Java"
- 使用 `topK` 控制返回数量（默认 5）
- 使用 `categoryKey` 缩小检索范围
- 如果检索结果不理想，调整查询词（更具体或更泛化）
- 检索阈值（`recallThreshold`）可在系统设置中调整

## 注意事项

- `rag_search` 返回的是语义匹配的文档片段，不是完整文档
- 片段可能不完整，需要时查看原始文档
- 知识库内容可能不是最新的，重要信息建议在对话中确认
- 检索结果包含 `source` 字段，可以追溯来源
