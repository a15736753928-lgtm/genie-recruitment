# 绩效分析技能

## 工作流

1. **查看概览**：`get_performance_stats` → 参与人数、平均分、优秀/待改进数
2. **部门对比**：`get_department_performance` → 各部门平均分排名
3. **等级分布**：`get_grade_distribution` → S/A/B+/B/C 各多少人
4. **季度趋势**：`get_quarter_trends` → 近 4 季度走势
5. **奖金管理**：`get_bonus_info` → 查看奖金池，`update_bonus` → 调整个人奖金
6. **发起考核**：`initiate_appraisal` → 为新季度创建考核记录

## 绩效等级

| 等级 | 分数范围 | 占比建议 | 奖金系数 |
|------|---------|---------|---------|
| S | 95-100 | ≤5% | 1.5x |
| A | 85-94 | ≤20% | 1.2x |
| B+ | 75-84 | ≤35% | 1.0x |
| B | 60-74 | ≤30% | 0.8x |
| C | <60 | ≥10% | 0x |

## 分析要点

- 识别"待改进"员工（C 等级），建议制定改进计划
- 识别"绩优"员工（S 等级），建议重点关注和保留
- 部门间绩效差异过大时（>15 分），标注可能存在评分尺度不一致
- 季度趋势连续下滑时，建议深入了解原因

## 注意事项

- 绩效数据涉及薪酬，回答时不要暴露个人具体薪资
- 季度格式：YYYY-QN（如 2026-Q3）
- 发起新考核会为所有参与员工创建绩效记录，操作不可逆
