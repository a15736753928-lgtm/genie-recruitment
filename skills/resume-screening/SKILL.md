# 简历筛选技能

## 工作流

1. **明确需求**：确认筛选的岗位（positionId）、数量（top N）、特殊要求
2. **拉取数据**：使用 `list_resumes` 获取候选人列表（先按岗位筛选，不足再全量）
3. **逐人深挖**：对候选列表中的 top 人选，使用 `get_resume` 查看详细分析
4. **多维度排序**：
   - 综合匹配分（首要排序依据）
   - 教育背景（学校层级、学历匹配度）
   - 工作经验（年限、行业、公司背景）
   - 技能匹配（核心技能覆盖度）
   - 项目经验（复杂度、角色）
5. **输出推荐**：Top N + 每人一句话理由 + 亮点 + 风险

## 筛选标准

### 教育背景优先级
- 985/211 优先（技术岗）
- 硕士优先于本科
- 专业相关度：对口 > 相关工科 > 其他

### 工作经验评估
- 匹配年限：JD 要求 ±2 年内为佳
- 行业经验：同行业 > 相关行业 > 跨行业
- 公司背景：大厂经历加分

### 技能评估
- 核心技术栈至少匹配 3 项
- 加分项：证书、开源贡献、技术博客、专利

## 输出格式

```
## 候选人推荐 — {岗位名}

| 排名 | 姓名 | 综合分 | 核心亮点 | 风险点 |
|------|------|--------|---------|--------|
| 1 | 张三 | 92 | Python精通，大厂3年 | 期望薪资偏高 |
| 2 | 李四 | 88 | 项目经验丰富 | 非985 |

> 以上排名基于简历匹配度评分，建议结合面试进一步评估。
```

## 注意事项

- 不要编造工具未返回的数据（姓名、公司、分数必须原样）
- 候选人状态为 "first_interview" 或 "second_interview" 时，标注"已在面试中"
- 不要主动做"成长建议""培养计划"，除非用户明确要求
- 推荐后附上可执行的操作按钮（查看详情、更新状态、生成面试题）
