Java 后端开发岗位的薪资范围参考：

| 级别 | 年限 | 薪资范围 | 备注 |
|------|------|---------|------|
| 初级 | 1-3年 | 12-18K | 应届或转行 |
| 中级 | 3-5年 | 18-28K | 独立负责模块 |
| 高级 | 5-8年 | 28-40K | 带团队/架构设计 |
| 专家 | 8年+ | 40K+ | 技术总监级别 |

**Why:** 2026年市场行情，基于近期 offer 数据和招聘平台统计。

**How to apply:**
- 筛选候选人时参考此薪资范围判断期望薪资是否匹配
- 如果候选人期望薪资超出范围 20% 以上，在推荐时标注"期望偏高"
- 此范围为北京/上海/深圳一线城市标准，二线城市打 8 折
