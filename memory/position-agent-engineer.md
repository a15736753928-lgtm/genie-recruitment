Agent 工程师（AI Agent 开发）岗位的筛选要点：

**必备技能：**
- Python 精通（3年以上）
- 熟悉 LLM API（OpenAI/Anthropic/DeepSeek 至少一种）
- 了解 Agent 框架（LangChain/LangGraph/AutoGen 至少一种）
- 有 RAG 系统开发经验

**加分项：**
- 有开源 Agent 项目或技术博客
- 了解 MCP (Model Context Protocol)
- 有生产环境 Agent 部署经验
- 熟悉向量数据库（Milvus/Pinecone/Weaviate）

**筛选策略：**
- 简历中同时出现 Python + LLM + LangChain → 高优先级
- 仅有 Python 无 Agent 经验 → 中优先级（可培养）
- 无 Python 但有 Java/Go + Agent 经验 → 中优先级（语言可转）

**Why:** 基于岗位 JD 和当前团队技术栈提炼。

**How to apply:**
- 使用 list_resumes 筛选时，关注技能标签匹配
- 在候选人推荐总结中，按必备技能匹配度排序
- 标注每个候选人的技能缺口（缺乏哪些必备技能）
